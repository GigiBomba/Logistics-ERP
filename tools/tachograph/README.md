# Tachograph Parser Tool

This directory should contain the `dddsimple.exe` binary used to parse
tachograph .DDD files.

## Setup

1. Download the latest Windows 64-bit binary from:
   https://github.com/traconiq/tachoparser/releases/latest

2. The file is usually named one of:
   - `dddsimple_windows_amd64.exe`
   - `dddsimple.exe`
   - `tachoparser_windows_amd64.zip` (extract `dddsimple.exe` from it)

3. Rename/copy it to this directory as `dddsimple.exe`.

**Do not commit this binary to git.** It is already excluded via `.gitignore`.
